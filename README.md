
# Form Design & Validation

A responsive and interactive Form Validation project built using HTML, CSS, and JavaScript.

## 🚀 Features

- Responsive form UI
- Input validation using JavaScript
- Email validation
- Password length validation
- Phone number validation
- Error and success messages
- Clean and modern design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

├── index.html
├── Form.css
└── form.js

## 📸 Output

This project validates user inputs and displays proper error or success messages.

## 🎯 Learning Outcomes

- Form handling
- DOM manipulation
- JavaScript validation
- Event handling
- User input processing
